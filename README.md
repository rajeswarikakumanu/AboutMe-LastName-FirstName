# About Me Website

A single-page personal website built with standard HTML and CSS.

## Run locally

1. Download or clone this repository.
2. Open `index.html` directly in Chrome or another browser.
3. No server or installation is required.

## Before deployment

Replace the `#` links in `index.html` with your actual GitHub, LinkedIn, portfolio, and project repository URLs.

## GitHub

```bash
git init
git add index.html README.md
git commit -m "Create About Me website"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/about-me.git
git push -u origin main
```

## Vercel

1. Sign in to Vercel with GitHub.
2. Select the `about-me` repository.
3. For a plain HTML site, no build command is required.
4. Deploy.
5. Vercel will provide a public URL.
