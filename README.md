## 💻 How to Run Locally

No server or installation is required.

### Step 1: Download the project

Download or clone this repository.

### Step 2: Open the project folder

Open the project folder in File Explorer or VS Code.

### Step 3: Open `index.html`

Double-click:

```text
index.html
```

The website will open in your default browser.

You can also right-click `index.html` and select:

```text
Open with → Google Chrome
```

## 🐙 GitHub Setup

Create a new repository on GitHub, for example:

```text
about-me
```

Then run the following commands in the project folder:

```bash
git init
git add .
git commit -m "Create About Me website"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/about-me.git
git push -u origin main
```

Replace:

```text
YOUR-USERNAME
```

with your GitHub username.

## 🌐 Deploy on Vercel

### Step 1

Go to Vercel and sign in using your GitHub account.

### Step 2

Click:

```text
Add New → Project
```

### Step 3

Select your GitHub repository:

```text
about-me
```

### Step 4

For this HTML project, no build command is required.

Use:

```text
Framework Preset: Other
Build Command: Leave empty
Output Directory: Leave empty
```

### Step 5

Click:

```text
Deploy
```

Vercel will automatically provide a public website URL.

Example:

```text
https://about-me-yourname.vercel.app
```
